# server-data — данные сервера для Modern Combat 5 Bridge

Встроенный сервер моста отвечает игре от имени серверов Gameloft. Для этого ему нужны справочные данные этих серверов:
каталог предметов, CRM (экономика, магазин, паки, бандлы, Lucky Spin, условия глав), шаблоны событий, картинки новостей
и промо, а также таблица глав и уровней игры. Они не входят в APK и в исходники и скачиваются отдельно.
**Без них сервер не запускается:** мост покажет «Нет данных сервера…».

Подходит к мосту версии **0.1** (Modern Combat 5 из Google Play 6.0.12a).

## Куда класть

Распакуйте `MC5-server-data-0.1.zip` так, чтобы на телефоне получилось:

```
/sdcard/BridgeGames/com.gameloft.android.ANMP.GloftM5HM/
    base.apk
    split_config.arm64_v8a.apk
    internal/
    external/
    server-data/
        ads_config.json
        ah/
            campaign.json  config.bin  crm.json  events.json  levels_07.json  meta.json  new_profile.json
        iris/
            game_object  events_HD_UPD18  videos_HD_UPD18  ban_tool_custom_messages  ...картинки
```

Проверка: файл `…/GloftM5HM/server-data/ah/crm.json` должен существовать. Если после распаковки получилось
`server-data/server-data/ah/…`, это тоже подходит.

Мост читает папку при каждом запуске сервера. Если положили её, когда мост уже работал, нажмите «Играть» ещё раз
(или перезапустите приложение).

### Сервер на компьютере

Для `server/mc5server.py` (режим «Подключаться к другому серверу»): положите содержимое `server-data` в `server/data/`
рядом с кодом или укажите папку параметром `--data <путь>` (или переменной `MC5_DATA`).

## Что внутри

| Файл | Что это | Откуда |
|---|---|---|
| `ah/crm.json` | CRM: экономика, предложения, паки, магазин, Lucky Spin, условия глав (`_zones_unlock`) | запись трафика Gameloft |
| `ah/events.json` | шаблоны событий (Activities, Battle Royale, сезоны лиг); сервер сдвигает их даты сам | запись трафика |
| `ah/config.bin`, `ah/new_profile.json`, `ah/levels_07.json` | конфиг игрового сервера, профиль нового игрока, блоки уровней кампании | запись трафика |
| `ah/campaign.json` | сюжетные миссии по главам и пороги опыта по уровням | память клиента 6.0.12a |
| `ah/meta.json` | служебное: что взято из записи | проект |
| `iris/*` | ассеты Iris: каталог предметов `game_object`, события/видео, тексты модерации чата, картинки новостей и промо | запись трафика |
| `ads_config.json` | таблица рекламных мест (реклама не показывается) | запись трафика |

Все эти данные принадлежат Gameloft. Они нужны только для совместимости с игрой, которая у вас уже есть.
Контрольные суммы — `SHA256SUMS` рядом с архивом.
