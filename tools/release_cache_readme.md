# MC5-cache-6.0.12a.zip — кэш игры для Modern Combat 5 Bridge

Всё, что нужно игре и встроенному серверу, кроме двух APK, — одним архивом. Мост распаковывает его сам при первом «Играть».
Подходит к мосту версии **0.1** и игре Modern Combat 5 из Google Play **6.0.12a**.

## Куда класть

Как есть, не распаковывая, рядом с APK игры:

```
/sdcard/BridgeGames/com.gameloft.android.ANMP.GloftM5HM/
    base.apk
    split_config.arm64_v8a.apk
    MC5-cache-6.0.12a.zip
```

Имя архива не важно. После первого запуска его можно удалить: он понадобится снова только для установки игры с нуля.
Порядок установки — `INSTALL.txt` релиза.

## Что внутри

| Путь в архиве | Куда мост распаковывает | Что это |
|---|---|---|
| `internal/files/assetpacks/` | приватная папка игры | паки игры (~1,4 ГБ; в Play их доставляет Play Asset Delivery) |
| `internal/files/didomi_*`, `internal/shared_prefs/*` | приватная папка игры | кэш конфига и данные согласия Didomi из установки Play |
| `external/bald/` | `Android/data/<пакет>/files/bald` | главы кампании (~0,8 ГБ) |
| `external/*.bin`, `dcsbin`, `InsTime` | `Android/data/<пакет>/files` | кэши Iris, флаги соответствия, состояние установщика |
| `server-data/` | приватная папка моста | справочные данные встроенного сервера: каталог предметов, CRM (экономика, магазин, паки, Lucky Spin, условия глав), шаблоны событий, картинки, таблица глав и уровней |

Учётки и сохранений в архиве нет: учётку создаёт сервер моста при первом входе.

### Сервер на компьютере

Для `server/mc5server.py` (режим «Подключаться к другому серверу») нужна только папка `server-data/` из архива: распакуйте её в
`server/data/` рядом с кодом или укажите параметром `--data <путь>`.

Все эти данные принадлежат Gameloft. Они нужны только для совместимости с игрой, которая у вас уже есть.
Контрольные суммы — `SHA256SUMS` рядом с архивом.
