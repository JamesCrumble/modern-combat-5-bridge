Modern Combat 5 Bridge — установка (Android 8+, arm64, без root)
================================================================

Modern Combat 5 из Google Play версии 6.0.12a без серверов Gameloft: мост готовит игру из ваших файлов и запускает
внутри неё свой сервер. Файлы игры и данные Gameloft в этот релиз не входят.

Что нужно
  1. Оригинальная игра Modern Combat 5 6.0.12a из Google Play (пакет com.gameloft.android.ANMP.GloftM5HM): два файла
     base.apk и split_config.arm64_v8a.apk. Их можно снять с телефона, где стоит игра из Play:
         adb shell pm path com.gameloft.android.ANMP.GloftM5HM
         adb pull <путь>/base.apk  и  adb pull <путь>/split_config.arm64_v8a.apk
     Другие версии игры не подходят: мост сверяет SHA-256 libMC5.so и скажет «unsupported game version».
  2. Данные игры той же версии — ОБЯЗАТЕЛЬНО:
       internal/  — содержимое /data/data/com.gameloft.android.ANMP.GloftM5HM/ (files/, shared_prefs/, databases/ ...);
                    главное в нём — files/assetpacks (паки игры, ~1,4 ГБ). Эта папка закрыта приложением: снять её с установки
                    из Play можно только на телефоне с root (или из своей резервной копии).
       external/  — содержимое /sdcard/Android/data/com.gameloft.android.ANMP.GloftM5HM/files/ (bald/ — главы кампании,
                    ~0,8 ГБ, кэши Iris, compliancy.bin ...). Её можно скопировать по adb (adb pull) с телефона, где игра скачала главы.
     Без паков игра не запустится; без bald/ главы будут просить «PRELOAD».
  3. Данные сервера server-data — отдельная загрузка (ссылка в описании релиза), см. её README.md.

Порядок
  1. Удалите с телефона игру из Google Play, если она стоит: подготовленная игра ставится под тем же пакетом.
  2. Установите MC5-Bridge-<версия>.apk (мост-установщик).
  3. Создайте папку  /sdcard/BridgeGames/com.gameloft.android.ANMP.GloftM5HM/  и положите в неё:
         base.apk
         split_config.arm64_v8a.apk
         internal/
         external/
         server-data/          (из загрузки server-data: внутри ah/, iris/, ads_config.json)
  4. Откройте мост, разрешите доступ ко всем файлам и уведомления, нажмите «Установить игру».
     Мост подготовит игру на телефоне (около минуты), попросит разрешить установку из этого источника и подтвердить установку.
  5. После установки мост предложит удалить сам себя — можно согласиться.
  6. Откройте «Modern Combat 5» (экран моста) и нажмите «Играть». При первом запуске данные из папки копируются на места,
     приложение закроется — откройте его снова и нажмите «Играть».

Ключ подписи
  Мост создаёт ключ на вашем телефоне и сохраняет его в той же папке (patched-apk.key). Не удаляйте его:
  по нему игру можно переустановить новой версией моста без потери сохранений. Если файл потерян, мост предупредит,
  что сохранения могут не подхватиться.

Прогресс
  Сервер хранит прогресс в приложении и копирует его в /sdcard/BridgeGames/com.gameloft.android.ANMP.GloftM5HM/mc5_state.json:
  после удаления и новой установки он подхватывается сам.

Настройки (экран моста)
  «Подключаться к другому серверу» — адрес другого телефона/компьютера с таким же сервером; «Доступ из локальной сети» — раздать сервер по Wi-Fi.

Исходники — MC5-Bridge-<версия>-src.zip. Контрольные суммы — SHA256SUMS.
