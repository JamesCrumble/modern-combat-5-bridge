# Modern Combat 5 Bridge 0.1

**Modern Combat 5 из Google Play 6.0.12a (arm64) без серверов Gameloft и без root.** Мост-установщик готовит игру из ваших
оригинальных `base.apk` и `split_config.arm64_v8a.apk` прямо на телефоне, ставит её под ключом вашего устройства и запускает
внутри неё свой сервер.

## Что работает
- Вход без учётки Gameloft: учётку и профиль создаёт свой сервер, прогресс хранится на телефоне (и копией в `BridgeGames`).
- Кампания: миссии, награды за них, звёзды, открытие глав по условиям (сюжет, звёзды, уровень).
- Экономика: Lucky Spin, боевые паки, бандлы, аренда оружия «TRY IT», ежедневные предложения.
- Магазин кредитов работает без Google Play: покупки проходят без оплаты.
- Ежедневные задачи и вехи Challenges, события по расписанию, кланы, чат (на этом сервере).
- «Подключаться к другому серверу» и «Доступ из локальной сети»: общий сервер на другом телефоне или ПК.

## Что не работает
- Мультиплеер (бой): своего игрового сервера пока нет.
- Повышение уровня с наградами, VIP-награды при смене уровня, эффекты классовых бандлов.
- Главы 4–6: часть условий (матчи в мультиплеере, отряд, тиры оружия, паки) сервер не считает — открываются пропуском за кредиты.

## Что в релизе

| Файл | Что это |
|---|---|
| `MC5-Bridge-0.1.apk` | мост-установщик (`com.jamescrumble.mc5bridge`) |
| `INSTALL.txt` | установка по шагам |
| `MC5-Bridge-0.1-src.zip` | исходники, из которых собран APK |
| `SHA256SUMS` | контрольные суммы |
| `server-data` (отдельная загрузка) | справочные данные серверов Gameloft для встроенного сервера, см. её `README.md` |

**Файлов игры и данных Gameloft в APK нет.** Нужны ваши: оригинальные APK игры 6.0.12a и её данные (паки и главы), см. `INSTALL.txt`.

Сторонние библиотеки: CPython 3.14 для Android (PSF), OpenSSL (Apache-2.0), Starlette/uvicorn и зависимости, smali/baksmali (BSD-3),
Guava (Apache-2.0), ANTLR runtime (BSD-3), apksig (Apache-2.0) — `NOTICE.md` в исходниках.
